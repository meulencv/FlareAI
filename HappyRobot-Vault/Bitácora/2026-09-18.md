# 2026-09-18 — Creación del agente de voz web

## Petición inicial
> "lee la documentación de happyrobot y creame un workflow sencillo para que con un voicecall
> web una web de habla me conteste solo eso"

El usuario pegó una API key (`sk_live_...JSs0`).

## Pasos realizados

1. Intenté leer `docs.happyrobot.ai` — bloqueada tras código de acceso. Encontré vía búsqueda
   web un perfil independiente (`api-evangelist/happyrobot` en GitHub) que reveló que el
   **OpenAPI está público** en `platform.happyrobot.ai/api/v2/docs/json`. Lo descargué y lo usé
   como fuente de verdad. → [[Qué es HappyRobot]]
2. Probé la primera key → `"invalid or revoked API key"` en host global. Probé host **EU** →
   funcionó (listó un workflow `test` preexistente). → [[Problemas y soluciones]] #1
3. Intenté crear el workflow con template `voice-agent` → `403 Cannot create use cases`
   (permisos de la key).
4. El usuario pegó una **segunda key** (`sk_live_...UUYeg`). Con ella, `voice-agent` dio error
   por falta de credenciales SIP → cambié a `inbound-voice-agent` (sin teléfono real). El
   usuario interrumpió aquí para confirmar: *"no no solo haz web call no telefono no real"* —
   confirma la decisión.
5. Creé el workflow **FlareAI Web Voice** desde template `inbound-voice-agent`, con prompt en
   español y mensaje inicial. → [[FlareAI Web Voice - workflow]]
6. Lo publiqué (`production`) y probé `POST /voice/tokens/` → devolvió token LiveKit válido.
7. Construí la web (`voice/server.py` + `voice/index.html`) — servidor intermediario que pide
   el token sin exponer la API key al navegador, y frontend con botón "Iniciar llamada" usando
   `livekit-client`. → [[Web app - server y frontend]]
8. Arranqué el servidor en background en `localhost:8000`. Usuario confirmó que estaba caído en
   un momento dado; lo reinicié con `nohup`.
9. Usuario preguntó si vería las llamadas en la web de HappyRobot → confirmé consultando
   `GET /workflows/{id}/runs`, salió un run `completed` de la prueba de token.
10. Usuario pidió que hablara en **español** → el nodo del agente tenía `language: en`,
    `voice: Paul`. Descubrí que la versión publicada estaba **bloqueada** para editar nodos
    (`Problemas y soluciones` #5) → hice unpublish → unlock → PUT nodo con voz **Ana HR**
    (es-ES) → publish. Verificado con GET del nodo. → [[FlareAI Web Voice - workflow]]
11. Usuario pidió crear este **vault de Obsidian** para documentar todo el proceso y poder
    retomarlo sin perder contexto.

## Resultado al cierre del día
- Workflow live en español, voz Ana HR.
- Web funcionando en `localhost:8000`.
- Vault creado en `HappyRobot-Vault/`.
