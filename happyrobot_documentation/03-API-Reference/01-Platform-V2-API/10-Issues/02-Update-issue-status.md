# Update issue status

> Updates the status of a quality issue (flag).



## OpenAPI

      requestBody:

                  status:

                    type: string
                required:
                  - id
                  - status
                  - updated_at
                additionalProperties: false
        '401':
          description: Default Response
          content:
            application/json:
              schema:
                type: object

                    type: string
                  message:
                    type: string

                    type: integer
