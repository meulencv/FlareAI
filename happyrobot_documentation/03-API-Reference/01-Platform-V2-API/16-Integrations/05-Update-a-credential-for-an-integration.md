# Update a credential for an integration

> Replaces an existing form-based credential's title and data while preserving its ID and workflow references. Send the same complete payload as credential creation, including all required data fields. If credential_type is omitted, the integration's default type is used; send it explicitly for a non-default type. Omitted tag_ids preserve existing tags; an empty array removes them. OAuth authorization flows must be completed in the HappyRobot platform UI. Credential secrets are never returned.
