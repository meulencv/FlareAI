# 3PL

> Integrate with 3PL Warehouse Manager

The 3PL integration connects your workflows to 3PL Warehouse Manager (3PL Central). Search for carriers, query loads by lane or reference number, and automate third-party logistics operations.

## Authentication

3PL uses a dialog-based configuration flow.

<Steps>
  <Step title="Enable the 3PL integration">
    Go to **Settings > Integrations** and enable **3PL**.
  </Step>

  <Step title="Add a credential">
    Click **Add Credential** and follow the configuration dialog to set up your 3PL connection.
  </Step>

  <Step title="Verify the connection">
    The credential will appear as **Active** once configured.
  </Step>
</Steps>

## Available events

### Actions

| Event                      | Description                                                  |
| -------------------------- | ------------------------------------------------------------ |
| **Find Carrier**           | Searches for carriers matching specified criteria            |
| **Find Load by Lane**      | Searches for loads matching origin/destination lane criteria |
| **Find Load by Reference** | Looks up a specific load by its reference number             |

## Example use case

A carrier calls asking about loads on a specific lane. The voice agent uses **Find Load by Lane** to search for available shipments, shares the details with the caller, and logs the carrier's interest for follow-up.
